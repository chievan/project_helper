# AI 仓库分析助手 (Project Helper)

基于 DeepSeek V4 + LangChain 的自动化 GitHub 仓库深度解读工具。

## 🌟 核心特性

- **深度架构分析**：自动克隆仓库，识别技术栈，扫描模块依赖。
- **万字解读报告**：生成包含项目概述、核心逻辑流、模块映射的专业级中文文档。
- **离线持久问答**：支持后台异步问答，刷新页面自动断点续传，不惧连接断开。
- **双阶段流式输出**：屏蔽协议乱码，纯净的打字机式交互体验。
- **响应式设计**：支持侧边栏缩放，完美适配各种屏幕尺寸。

## 🚀 快速开始

### 后端 (FastAPI)
1. 进入 `backend` 目录，创建虚拟环境。
2. 安装依赖：`pip install -r requirements.txt`
3. 配置环境变量：`.env` 中设置 `DEEPSEEK_API_KEY`。
4. 启动服务：`uvicorn app.main:app --reload --port 8502`

### 前端 (Vue 3 + Vite)
1. 进入 `frontend` 目录。
2. 安装依赖：`npm install`
3. 启动开发服务器：`npm run dev`

## 🛠 未来优化路线图 (Roadmap)

### 1. RAG 架构升级 (最高优先级)
- **向量存储**：引入 ChromaDB 或 Qdrant，将代码库切片并向量化。
- **精准检索**：问答时仅检索相关代码片段，将 Token 消耗降低 80% 以上，支持超大型项目。

### 2. 模型分层 (Performance vs Cost)
- **Flash 模式**：使用极速模型（如 Gemini Flash）处理目录扫描、文件汇总等低推理任务。
- **Pro 模式**：仅在生成核心报告和复杂 Q&A 时调用最强推理模型，平衡速度与质量。

### 3. 代码图谱可视化
- 引入 Mermaid.js 或 Canvas，动态渲染项目的模块调用关系图。

### 4. 本地化部署支持
- 支持 Ollama 接入，实现完全本地的代码库分析，保护隐私。
